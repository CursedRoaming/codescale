安全说明

凭证保存位置、权限边界、页面请求行为与运维交接约定。面向使用者的是第 01 节，面向开发者的是第 02 节。
页面说明　本站不设账号密码输入框，不接收 token，不上传台账内容。 账号密码仅在对应平台的官方网站输入，不经过本站。
01

凭证与数据边界

作为责任边界
  • 不保存明文密码。 Kalodata 登录由使用者在浏览器内自行完成，脚本不读取、不保存、不传输密码，仅保留浏览器会话。
  • 凭据仅存本机。 token 保存在执行脚本设备的 ~/.workbuddy/secrets/meli/ 目录，不进入网页、公开仓库或聊天工具。
  • 原始表不留副本。 项目结束后删除。报告中不出现客户个人信息，未经许可不对外发布。
  • 页面不请求外部服务。 接入中心的台账只写入本机浏览器的 localStorage，键名 codescale.connect.v1。页面在打开与填写过程中均不发起网络请求。
02

运维交接

内部 供开发者参考

以下命令均在本机执行。GitHub Actions 不持有浏览器会话或 token，仅负责发布。

凭证位置与说明
美客多应用凭证~/.workbuddy/secrets/meli/app.json　App ID 与 Secret Key
美客多 token~/.workbuddy/secrets/meli/token.json　由脚本写入，不手工修改
Kalodata 会话~/.workbuddy/secrets/kalodata/state.json　浏览器登录态，不含密码
仓库排除规则以上目录均不在 09_码尺平台/ 内，已由 .gitignore 排除

执行顺序　前置条件：在 developers.mercadolivre.com.br 创建应用，Redirect URI 填写 http://localhost:3333/callback，权限勾选 read 与 offline_access。

python pipeline/tools/meli_auth.py      # 完成浏览器授权，token 自动落盘
python pipeline/tools/meli_token.py     # 自动续期，access_token 6 小时、refresh 180 天
python pipeline/tools/meli_probe.py     # 试拉巴西穿戴甲数据，核对字段是否满足定价需要

会话失效时，「数据源健康」面板会显示 blocked，不会静默返回空数据。重新执行第一条命令即可。python 需指向已安装 playwright 的解释器，PowerShell 中的默认 python 可能指向 WindowsApps 的空壳。

03

发布与归档

项目说明
自动运行每日 20:00 生成一份不可变快照与报告。历史快照不随后续运行改写。
发布范围只有站点文件、数据与报告进入公开仓库。凭证目录与账号清单不在仓库内。
报告内容只含商品行情与成本测算，不含订单明细、客户个人信息或客户后台数据。
边界　本站不收集账号、密码或 token。无表单、无提交、无上报
