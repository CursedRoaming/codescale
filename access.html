给川哥的部分看 01 和 02。交接的看 04。所有命令都在本机跑，这个网页只做说明。它不收集任何东西。

01

你只需要做两件事

给川哥 · 约两分钟

其余全部由我们完成。你不用装软件，不用发账号密码给我们，也不用在任何表格里填 token。

1

确认用哪个账号

美客多开放平台需要一个美客多账号登录，用来建一个叫 codescale 的应用。用主店账号还是单独注册一个，你定。这一步决定后面所有授权归在谁名下，所以由你来定，我们不替你选。

2

点一次「同意授权」

应用建好后，我们会给你一条美客多官方授权链接。你在浏览器打开，登录，看到应用 codescale 申请读取公开商品数据，点同意就结束了。

链接的域名是 auth.mercadolivre.com.br，不是我们的网站。密码只输在美客多官网。授权成功后，脚本在本机自动拿到凭据，你这边什么都不用发。

02

授权时能看见什么

我们拿不到什么

把边界摆明，比让你盲点同意更稳妥。下面每一条都可以在授权页上核对。

项目实际情况
应用名codescale，码尺这一个项目，没有别的应用
申请的权限read 只读，加 offline_access 长期有效。后者只是免得每天重新授权，不是扩大读取范围。没有 write，没有写权限
你能读到的巴西站公开商品的标题、标价、销量、上架时间、单品链接
我们读不到的店铺后台、订单明细、收款账户、广告花费、任何客户个人信息
你不需提供的店铺后台密码、订单导出、财务报表、合同原件
随时可撤销在美客多后台取消授权即可，撤销后我们立刻失去读取能力
03

我们的三条硬约定

写在这里，出问题照此追责
  • 不存明文密码。 Kalodata 那次登录，账号密码是我们自己在浏览器里输的，脚本不碰、不存、不传。只留浏览器的登录会话。
  • 凭据只落本机。 token 存在跑脚本那台机器的 ~/.workbuddy/secrets/meli/，不进网页、不进公开仓库、不发到任何聊天工具。
  • 原始表不留副本。 项目结束删除。报告里不出现客户个人信息，未经同意不对外讲。
04

内部交接

内部 换人接手照这个走

这一段是给我们自己看的。命令都在本机执行，GitHub Actions 上没有浏览器会话，也没有 token，只负责发布。

凭证位置与说明
美客多应用凭证~/.workbuddy/secrets/meli/app.json　App ID 与 Secret Key，两行 JSON
美客多 token~/.workbuddy/secrets/meli/token.json　脚本自动写，不手工改
Kalodata 会话~/.workbuddy/secrets/kalodata/state.json　浏览器登录态，不含密码
绝不进仓库以上三个目录都不在 09_码尺平台/ 里，已被 .gitignore 排除

三步跑通

前置：在 developers.mercadolivre.com.br 建应用，Redirect URI 填 http://localhost:3333/callback，Scope 勾 read 和 offline_access。

python pipeline/tools/meli_auth.py      # 浏览器点授权，token 自动落盘
python pipeline/tools/meli_token.py     # 自动续期，access_token 6 小时、refresh 180 天
python pipeline/tools/meli_probe.py     # 试拉巴西穿戴甲，看字段够不够定价

会话失效时，看「数据源健康」面板会变成 blocked，不会静默交空数据。重跑第一条即可。python 要用装了 playwright 的那个解释器，PowerShell 里的 python 可能指向 WindowsApps 的空壳。
