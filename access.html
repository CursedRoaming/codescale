接入说明与安全约定

面向使用者的是第 01 与 02 节，面向开发者的是第 04 节。所有操作在本机执行，本页仅提供说明，不收集任何数据。
页面说明　本页不含输入框与提交操作，不保存任何填写内容。 账号密码仅在对应平台的官方网站输入，不经过本页。

如需查看可选数据渠道，或记录接入进度，请使用渠道接入中心 →。 该页的台账仅保存在使用者本机，同样不上传。

01

授权操作步骤

约两分钟

使用者只需完成以下步骤，其余配置由开发者处理。无需安装软件，无需向本平台提供账号密码或 token。

1

确定授权主体

美客多开放平台需要一个美客多账号，用于创建名为 codescale 的应用。使用主店账号或单独注册，由使用者决定。该选择决定后续授权的归属。

2

确认授权

应用创建后，开发者提供一条美客多官方授权链接。使用者在浏览器打开并登录，确认应用 codescale 申请读取公开商品数据后，点击同意即可。

链接域名为 auth.mercadolivre.com.br，非本平台域名。密码仅在美客多官网输入。授权成功后，脚本在本机取得凭据，使用者无需发送任何信息。

02

权限范围

授权页可逐项核对

以下列出应用申请的权限与不可访问的数据范围。

项目实际情况
应用名称codescale，仅用于本项目
申请权限read 只读，以及 offline_access 长期有效。后者用于避免重复授权，不扩大读取范围。未申请 write 权限
可读取数据巴西站公开商品的标题、标价、销量、上架时间与单品链接
不可读取数据店铺后台、订单明细、收款账户、广告花费，以及任何客户个人信息
无需提供店铺后台密码、订单导出文件、财务报表、合同原件
撤销方式在美客多后台取消授权。撤销后本平台立即失去读取能力
03

平台安全约定

作为责任边界
  • 不保存明文密码。 Kalodata 登录由使用者在浏览器内自行完成，脚本不读取、不保存、不传输密码，仅保留浏览器会话。
  • 凭据仅存本机。 token 保存在执行脚本设备的 ~/.workbuddy/secrets/meli/ 目录，不进入网页、公开仓库或聊天工具。
  • 原始表不留副本。 项目结束后删除。报告中不出现客户个人信息，未经许可不对外发布。
04

运维交接

内部 供开发者参考

以下命令均在本机执行。GitHub Actions 不持有浏览器会话或 token，仅负责发布。

凭证位置与说明
美客多应用凭证~/.workbuddy/secrets/meli/app.json　App ID 与 Secret Key
美客多 token~/.workbuddy/secrets/meli/token.json　由脚本写入，不手工修改
Kalodata 会话~/.workbuddy/secrets/kalodata/state.json　浏览器登录态，不含密码
仓库排除规则以上目录均不在 09_码尺平台/ 内，已由 .gitignore 排除

执行顺序

前置条件：在 developers.mercadolivre.com.br 创建应用，Redirect URI 填写 http://localhost:3333/callback，权限勾选 read 与 offline_access。

python pipeline/tools/meli_auth.py      # 完成浏览器授权，token 自动落盘
python pipeline/tools/meli_token.py     # 自动续期，access_token 6 小时、refresh 180 天
python pipeline/tools/meli_probe.py     # 试拉巴西穿戴甲数据，核对字段是否满足定价需要

会话失效时，「数据源健康」面板会显示 blocked，不会静默返回空数据。重新执行第一条命令即可。python 需指向已安装 playwright 的解释器，PowerShell 中的默认 python 可能指向 WindowsApps 的空壳。
